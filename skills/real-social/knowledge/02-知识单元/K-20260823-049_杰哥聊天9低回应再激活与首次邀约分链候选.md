# 杰哥聊天9低回应再激活与首次邀约分链（候选）

## 分链结构

```text
长期低回应/无回复
  -> 新主题再激活
  -> 铺垫邀约
  -> 时间、地点、交通、方便与顾虑核对
  -> 来源报告首次见面
```

## 与既有分链的关系

- 与 `K-20260822-031` 共享重启和具体调度主题，但这里的起点是长期低回应/无回复，不是先前安排失败后的暂停。
- 与 `K-20260822-032`、`K-20260822-037` 共享时间、地点、交通和变更条件；这些只是计划协商信号，必须另行确认意图、方便和安全。

## 节点与限制

1. **低回应/无回复**：只记录来源报告的消息状态，不推断原因。
2. **再激活**：新的自然主题得到连续回应后，才重新判断是否可以谈现实接触。
3. **铺垫邀约**：来源在天气和活动话题中逐步提及见面；运行时不能把来源的性化或强势表达当作必需动作。
4. **调度核对**：时间、地点、交通、同行、外貌顾虑和方便程度需要分别确认。
5. **首次见面**：本案只有来源报告，不能替代双方明确同意、现场安全和后续结果证据。

## 调用边界

来源将天气、吃饭回答、表情和犹豫解释为窗口或假性拒绝，这部分只作为 `source_interpretation` 保存。明确拒绝、不适、停止或删除时，优先使用停止边界；本分链不提供固定等待天数、施压方法或可复制话术。
