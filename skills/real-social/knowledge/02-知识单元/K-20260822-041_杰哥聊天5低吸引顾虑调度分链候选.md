# 杰哥聊天5低吸引顾虑调度分链（候选）

## 分链结构

```text
激活/低吸引
  -> 同理心与轻量主题
  -> 轻量邀约试探
  -> 疲劳/工作限制
  -> 暂停
  -> 新互动重启
  -> 社恐/冷场顾虑承接
  -> 排假与具体条件
  -> 时间、同行、地点调度
  -> 签约/见面候选
```

## 节点与转移条件

1. **激活/低吸引**：线下接触短、微信转接后上下文少；不能把加微信本身当作强兴趣。
2. **同理心与轻量主题**：对方继续回复，聊天可从个人判断或近况延展；是否进入邀约要看连续参与。
3. **疲劳/暂停**：对方明确说困、上班累或不方便时，先允许本次不执行。
4. **新互动重启**：暂停后出现新的消息或情绪内容，再重新评估，而不是按天数自动重启。
5. **顾虑承接**：对方明确说社恐、怕冷场或担心互动质量；先处理顾虑，再看是否继续讨论见面。
6. **具体调度**：排假、休息日、同行、地点和当天状态逐项出现时，进入双向条件确认。
7. **签约候选**：只有双方愿意且方便、条件可执行时才可进入；来源报告的见面结果仍是 `source_reported`。

## 与其他分链的关系

- 与 `K-20260822-031`、`K-20260822-035` 共享“暂停 -> 新证据重启”，但本分链新增低吸引和社恐/冷场顾虑节点，不把长周期等待当核心。
- 与 `K-20260822-036` 共享顾虑和条件调整，但本分链发生在初始吸引较弱、先暂停再重启的背景中。
- 与 `K-20260821-020`、`K-20260821-021` 互相约束：低回应可减少投入，明确停止则退出，不得用顾虑承接绕过边界。

## 运行限制

- 不把同理心、幽默或来源的窗口判断当成必然吸引。
- 不把社恐、疲劳和排假当作测试或需要突破的信号。
- 不把八天、任何固定间隔或语音消息当作阶段条件或电话许可。
- 只提供阶段和方向判断，不由分链生成完整回复。
