# 亲密话题强度随反馈调节方向（候选）

## 来源逻辑

该方向不是“如何说一句性话题”，而是判断何时继续、何时降级：

```text
已有相关语境
-> 低强度进入
-> 对方是否主动延展或持续同频道
   -> 是：维持或小幅提高
   -> 否：降低、换线或暂停
-> 出现明确停止：结束该主题
```

三周目案例的重要价值是同时展示了讲解者认为有效的表达、学员A过于直接的失误，以及对方不接后如何撤回。后续案例应继续验证这套进退逻辑，而不是积累孤立话术。
