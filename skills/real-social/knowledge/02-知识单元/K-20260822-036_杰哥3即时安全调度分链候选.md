# 杰哥3即时安全调度分链（候选）

## 分链结构

```text
激活
  -> 同频道/舒适调整
  -> 主题/邀约
  -> 形式与安全条件调整
  -> 当日调度
  -> 签约/到达候选
```

这里的“安全条件”只指对方在材料中明确提出的形式、时间、休息、地点或公开场所等条件；它不是模型对对方心理或风险的自动推断。

## 节点与转移条件

1. **激活**：加微信后出现连续互动和对方主动解释。
2. **同频道/舒适调整**：对方表达紧张、尴尬或自我评价，双方仍继续交流；先处理已说出的不适。
3. **主题/邀约**：现实接触目标被明确提出，出现当日或近期可用时间。
4. **形式与安全条件调整**：对方说明不喝酒、想休息、交通或场所限制，双方改用另一可执行方案。
5. **当日调度**：确认时间、地点、迟到、当前位置和临时变更。
6. **签约/到达候选**：出现双方明确确认和可执行到达信息；来源报告的到门口仍属于 `source_reported`。

## 与长周期分链的关系

该分链与 `K-20260822-035` 都复用激活、主题、邀约和调度节点，但转移速度、条件处理和暂停方式不同。短周期并不代表更高兴趣，长周期也不代表更低兴趣；两者先作为并行路径保存。

## 运行限制

- 不用“立即回复”“某分钟内”作为硬阈值。
- 不把一次“可以”、表情或定位当作完整签约。
- 对方提出休息或不喝酒时，先核对是否愿意继续本次安排。
- 命中明确拒绝或整体停止时，停止本分链。
