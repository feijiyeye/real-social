# 杰哥案例回撤重启邀约分链（候选）

## 分链结构

```text
激活/前提
  -> 主题/邀约
  -> 调整（评价、顾虑、意图与需求感）
  -> 调度尝试
  -> 回撤/暂停（本次安排未成）
  -> 重启（出现新的互动证据）
  -> 重新调度
  -> 签约候选
```

这里的“回撤/暂停”是本案的路径描述，不自动等同用户术语中的“断裂期”。如果后续案例显示同一节点和转移条件稳定出现，再考虑合并；若出现不同重启原因或不同顺序，保留并行分链。

## 节点与转移条件

1. **激活/前提**：初次接触后出现微信互动，并开始交换与后续见面相关的信息。
2. **主题/邀约**：对话明确转向见面、饮品、时间或地点；来源仍会用调侃和评价维持调整。
3. **调整**：对方提出时间、疲劳、社恐、形式、目的或安全顾虑，双方在来源叙事中来回校正。
4. **调度尝试**：出现具体可用时间、地点或次日安排，但尚未完成执行。
5. **回撤/暂停**：当次安排因日程或状态未执行，一方接受暂停；不能把它自动解释成拒绝或测试。
6. **重启**：间隔后出现新的联系和可观察回应；仅凭回复本身还不能确认回到邀约阶段。
7. **重新调度/签约候选**：重新确认双方意图、时间、地点和条件，出现可执行安排或在路上的来源报告。

## 与既有分链的关系

`K-20260822-026` 的“断裂期”链条来自更长的跨城案例，强调低回应、顾虑和关系维持。本案的暂停更像一次邀约日程失败后重启，因此先分开保存，不把两个节点强行同义化。

## 限制

- 所有节点映射都来自讲解者复盘，不是独立原始聊天观察。
- 具体等待天数只属于本案叙事，不是触发阈值。
- 重新回复、询问位置或到达地点不能替代明确意愿和边界核对。
