# 杰哥聊天8平台迁移与主动邀约经典案例（候选）

## 案例定位

这是独立的讲解型经典案例。与已有邀约案例相比，本案的独特节点是从 APP 交流迁移到微信后，对方继续追问并明确提出可用时间和约会。来源使用“高位框架/逆转框架”等术语，但知识层只保留可观察行为和来源解释的区别。

## 六层证据

| 层 | 来源材料中的内容 | 证据等级 |
| --- | --- | --- |
| `source_dialogue` | 来源转述问候、位置、在读书、年龄/经历、星座、朋友圈、转微信、回复速度和约会询问。 | `source_reported`，缺原始导出 |
| `source_interpretation` | 来源把追问、自我呈现、星座和时间询问解释为购买欲、框架逆转和兴趣指标。 | 来源观点，不是单项事实 |
| `source_move` | 来源采用如实身份回答、自我呈现、深层主题、平台迁移、推开/拉回和地点建议。 | 操作按调用状态分层 |
| `source_feedback` | 材料报告女性A持续追问，转微信后仍关注经历和时间，最后提出可约时间及“可以约会吗”。 | `source_reported` |
| `source_principle` | 来源强调回答后要连接下一个主题、平台迁移要自然、短句能维持价值感；这些先作为观点/方向候选。 | `viewpoint/source_only` |
| `source_outcome` | 来源报告约小酒馆并称可快速收尾；没有独立见面或后续质量证据。 | `source_reported` |

## 候选分链

```text
APP 激活
  -> 信息与标准呈现
  -> 深层主题
  -> 平台迁移
  -> 对方主动提出邀约
  -> 时间/地点调度候选
```

## 调用分层与边界

平台迁移、连续追问和明确约会询问可作为候选案例的观察材料；“舔狗、购买欲、框架逆转”是来源语言，不是体系价值观；酒精降低防备、私密空间和快速收尾只保留为边界审计，不作为默认方向。

## 限制与待验证

1. 平台迁移的触发条件是否稳定，需有迁移后没有邀约的反例。
2. 对方提出“什么时候有空/可以约会吗”比星座或朋友圈信息更具体，但仍需确认双方是否愿意且方便。
3. 来源没有证明自我失格、推开/拉回或酒精主张的效果，不能从一次案例推导规则。
4. 结果和关系性质均为 `source_reported`，不承诺复现。
