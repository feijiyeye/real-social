# 吸引联系与短期长期属性的动态调整规则（候选）

## 条件化表达

当对方仍持续参与，但开始表达认真程度、安全、异地或是否只想短期等顾虑时，来源优先把任务从继续制造吸引转为补联系感、信任感、长期属性和真实意图；只有当互动重新稳定且主题需要被带回时，再恢复男女意图或邀约方向。

## 反馈循环

```text
识别当前反馈
-> 判断主要缺口（吸引 / 联系 / 短期 / 长期 / 顾虑）
-> 选择本轮方向
-> 观察对方是否接住、回避、提出新问题或降低反馈
-> 继续 / 降低强度 / 换线 / 暂停 / 回到邀约
```

这条规则解释了案例为什么多次从调情转日常、从普通聊天回到邀约、从吸引转安全感。它不是固定回合流程，也不是一句话术。

## 待验证

- 四项变量是否足以覆盖其他经典案例；
- 联系感、信任感和安全感是否需要拆成独立维度；
- 哪些可观察信号可以稳定判断“吸引已有但信任不足”；
- 与用户术语“适配中期｜调整”的正式对应关系。
