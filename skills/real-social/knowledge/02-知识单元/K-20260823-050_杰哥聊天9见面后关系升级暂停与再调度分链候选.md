# 杰哥聊天9见面后关系升级、暂停与再调度分链（候选）

## 分链结构

```text
首次见面（来源报告）
  -> 线上关系升级/反馈不确定
  -> 亲密话题试探、换线或抽离候选
  -> 生病/疲劳等现实限制
  -> 当次暂停
  -> 恢复后新证据重启
  -> 日期、排假、位置、外貌准备与方便核对
  -> 再次调度候选
```

## 与既有分链的关系

- 与 `K-20260822-027` 的动态调整候选共享“吸引、联系感和长期/短期解释之间切换”，但本分链增加首次见面后的上下文和生病暂停。
- 与 `K-20260822-028`、`K-20260823-043` 共享亲密话题反馈审计；本单元默认 `boundary_only`，不把来源性操作变成方向。
- 与 `K-20260822-031`、`K-20260822-041` 共享暂停后重新调度，但本案的暂停原因是身体状态，且第二部分明确承接首次见面，不能按长周期等待或低吸引案例直接替代。

## 节点与限制

1. **见面后线上反馈**：见面本身是来源报告，不能补写现场同意或关系质量。
2. **关系升级/反馈不确定**：把来源的吸引力下降、喜欢和购买度判断留在 `inferred`，只观察实际回应和顾虑。
3. **现实限制暂停**：生病、疲劳或不方便先按限制处理，允许当次不执行。
4. **新证据重启**：恢复、明确活动意图、日期和请假是新的计划信息，但仍要重新确认愿意、方便和安全。
5. **再调度**：日期、地点、排假、外貌准备和到达只属于执行条件，不自动扩展为亲密或私密空间许可。

## 调用边界

来源中的性化画面、称呼控制、强势推进、把“想聊/想见”当成喜欢和把暂停解释为可继续，只保留在原始资料和案例层。若出现明确不适、停止、拒绝或删除，先按停止边界退出；后续任何恢复都需要新的明确证据。
