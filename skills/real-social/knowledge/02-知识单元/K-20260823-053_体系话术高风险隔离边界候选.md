# 体系话术高风险隔离边界（候选）

## 核心边界

本批材料完整保留，但以下来源内容不能成为默认回复：

1. **侮辱与贬损**：通过外貌、身材、年龄、智力、职业、地域、性经验或群体身份打击对方。
2. **拒绝后突破**：把拒绝、不适、害怕、慢热、改期或不方便解释成测试、借口或需要攻破的阻碍。
3. **欺骗与隐瞒**：假熟人、错误记忆、虚构经历、隐瞒伴侣/多偶状态、伪装真实目的或制造第三方危机。
4. **控制与奖惩**：随机冷热、惩罚式消失、要求服从、让对方完成任务换取基本尊重，或用嫉妒制造不安全感。
5. **性与私密空间风险**：未经双方明确进入同类语境就露骨评价身体或描述性行为，或把“不会发生性行为”作为进入私密空间后再反转的策略，仍属边界内容；双方明确进入同类性话题后，符合条件的露骨表达可进入候选参考，但不得含有威胁、羞辱、欺骗、强迫或私密空间诱导。
6. **线下越界**：触碰、接吻、距离压近、观察非语言反应后继续升级等线下操作，不属于线上回复 Skill。

## 可保留但不默认调用

- 假评、推拉、失格、废物测试、框架、高位点评等并非按章节整类删除，但必须逐句判断。轻度、明显虚构且双方能识别的玩笑可以作为 `context_required` 候选；真实痛点、羞辱和施压不行。
- 露骨性话题不再一律标为 `not_default_direction/boundary_only`：双方明确进入同类性话题并满足成年/身份依据、互惠反馈和退出条件时，相关原句可标为 `candidate_callable_after_context_review`；未满足条件或含有施压、羞辱、欺骗、强迫、私密空间诱导的条目仍为 `boundary_only` 或 `not_default_direction`。
- 来源中的“可以随时离开”“会尊重选择”等表达，只有在它们是真实承诺并被实际遵守时才有正向意义；若只是降低戒备后反转意图，仍属于欺骗边界。

## 命中边界后的替代方向

```text
真实顾虑 -> 澄清具体顾虑或接受限制
明确拒绝/停止 -> 停止当前话题；明确结束全部互动时整体停止
低回应 -> 减少投入或暂停，不连续追问
邀约条件不合适 -> 协商替代时间/形式，不能把原因贬为借口
关系状态问题 -> 如实回答，不隐瞒、不制造第三方竞争
亲密话题反馈不清 -> 降低强度、换线或暂停
```

## 与来源保真的关系

高风险条目仍保存在原件和去重索引中，用于理解体系、查重、案例复盘和边界审计。`source_preserved` 不等于认可，`boundary_only` 不等于删除。未来若用户对某一类作出更细裁决，只更新调用状态和条件，不改写原始证据。
