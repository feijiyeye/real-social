# 杰哥2长周期邀约等待重启分链（候选）

## 分链结构

```text
激活/前提
  -> 主题/邀约
  -> 具体日期
  -> 有理由改期
  -> 暂停与间隔
  -> 新证据重启
  -> 详细行程确认
  -> 当日调度/签约候选
```

这条分链与 `K-20260822-031` 的共同点是“安排未成后接受暂停，再由新互动重启”；区别是杰哥2包含多次明确改期、远期日期和较长的等待，且最后靠详细行程说明回到可执行安排。当前不把“长周期”或“坚持”建成时间规则。

## 节点与转移条件

1. **激活/前提**：初识后有连续文字互动，初次消息仍能连接到现实背景。
2. **主题/邀约**：出现明确的见面意图和时间询问。
3. **具体日期**：对方给出某个可用日期或时间，形成第一次调度。
4. **有理由改期**：对方提前解释冲突，并提出替代安排；不自动等同拒绝。
5. **暂停与间隔**：当前安排暂不执行，双方没有持续追加；间隔长度只作背景。
6. **新证据重启**：出现新消息、近况、位置或日期信息后，重新判断是否回到邀约。
7. **详细行程确认**：顾虑、出差、疲劳、替代日期和当天条件被具体说出，进入双向调度候选。

## 运行限制

- 单次慢回、表情或“OK”不能启动该分链。
- 不能把“未回城”或模糊回复解释成隐藏同意。
- 明确停止全部互动时，直接进入停止边界。
- 分链只帮助识别状态和转移条件，不决定下一句，也不生成话术。
