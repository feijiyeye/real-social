# 杰哥4删除后修复重启分链（候选）

## 分链结构

```text
激活/前提
  -> 主题/邀约
  -> 首次见面
  -> 见面后明确不适/停止
  -> 删除联系
  -> 验证与边界表达
  -> 对方自愿重新通过
  -> 舒适感/意图重新判断
  -> 再次调度候选
```

## 节点与转移条件

1. **首次见面与线上回流**：线上互动已经转入过现实接触；线下部分只作为案例上下文。
2. **不适/停止**：对方明确表达不适、质疑行为或停止回应。先进入停止边界，不把它解释成测试。
3. **删除**：出现删除联系时，普通低回应重启方向暂时失效；不能靠固定天数自动跳转。
4. **验证与边界表达**：本案来源报告对方在验证消息中直接表达担忧。该表达是边界证据，不是积极许可。
5. **自愿恢复**：重新通过并继续互动后，才有新的阶段证据；恢复程度仍需结合后续内容判断。
6. **修复后再调度**：若对方明确愿意继续现实接触，才可重新进入邀约条件核对；不从案例结果推导必然成功。

## 与其他分链的关系

- 与 `K-20260821-020` 的低回应减少投入不同：本分链有明确不适、删除和后续边界表达，不能只按低回应处理。
- 与 `K-20260821-021` 的停止边界互相约束：明确停止优先，只有对方后续自愿恢复才重新观察。
- 与 `K-20260822-031` 的回撤重启不同：本分链发生在首次见面后的关系损伤之后，不能用普通日程暂停的逻辑覆盖。

## 运行限制

- 不设置“几天后再联系”或“验证消息模板”。
- 不把重新通过、表情、继续回复自动解释为对先前行为的同意。
- 不把线下身体接触、接吻或来源责任论迁移到线上方向。
- 发现明确结束全部互动时，退出本分链。
