# 杰哥聊天8平台迁移与主动邀约分链（候选）

## 分链结构

```text
APP 激活
  -> 信息/标准呈现
  -> 深层主题
  -> 平台迁移
  -> 对方主动提出邀约
  -> 时间/地点调度候选
```

## 与既有分链的关系

本分链复用 `K-20260822-026` 的激活/主题/调整节点和 `K-20260822-032` 的双向调度方向，但新增“平台迁移”这一转移条件；不把平台迁移本身视为兴趣或同意证据。

## 运行限制

来源的“框架逆转”“购买欲”“舔狗”和酒精效果均保留在案例层，不能作为默认调用规则。运行时要把平台选择、现实邀约、电话许可和亲密同意分别判断。
