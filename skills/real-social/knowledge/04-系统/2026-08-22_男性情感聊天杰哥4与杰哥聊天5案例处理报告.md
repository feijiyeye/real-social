## 四、案例一：杰哥4删除后修复与重启

### 候选分链

```text
激活/前提
  -> 主题/邀约
  -> 首次见面
  -> 见面后明确不适/停止
  -> 删除联系
  -> 验证与边界表达
  -> 对方自愿重新通过
  -> 舒适感/意图重新判断
  -> 再次调度候选
```

### 六层提炼

- `source_dialogue`：字幕转述酒吧门口初识、姓名/年龄、两性话题、短期/长期属性、时间地点、收拾、同行、见面后的牵手/拥抱/接吻、对方质疑“需要征求意见”、停止回应、删除、验证消息和重新通过。
- `source_interpretation`：讲解者把姓名、表情、个人信息和“哪里人”等解释为窗口或兴趣，把自我解释和性话题解释为属性、测试或吸引，把删除后的验证消息解释为需要补舒适感；这些都是来源判断，不是独立事实。
- `source_move`：来源采用年龄与属性试探、直接邀约、时间地点调度、线下升级、删除后的验证消息、长期属性补充和幽默修复。线下身体升级及“扛责任”论完整保留在案例层，但不进入线上默认方向。
- `source_feedback`：材料报告对方在见面后抗拒并停止回应，几天后删除；验证消息中明确表达“太可怕、第一次见面就接吻”，随后重新通过并继续互动。
- `source_principle`：来源将本案称为挽回案例，并同时提醒普通用户不建议主动挽回。体系层可复用的是“明确不适/删除与普通低回应不同；只有对方自愿恢复后才重新观察”，不是固定挽回方法。
- `source_outcome`：来源报告重新通过并在后续继续互动/同场活动；无独立原始导出、同意过程、见面质量或后续关系证据，结果状态为 `source_reported`。

### 调用边界

`K-20260822-038` 可作为相似案例候选召回，帮助识别“见面后不适/删除—边界表达—自愿恢复”的特殊路径。不得把删除、验证消息回复或后来恢复解释成对先前行为的同意；明确结束全部互动时仍优先停止。

## 五、案例二：杰哥聊天5低吸引、顾虑承接与邀约

### 候选分链

```text
激活/低吸引
  -> 同理心与轻量主题
  -> 轻量邀约试探
  -> 疲劳/工作限制
  -> 暂停
  -> 新互动重启
  -> 社恐/冷场顾虑承接
  -> 排假与具体条件
  -> 时间、同行、地点调度
  -> 签约/见面候选
```

### 六层提炼

- `source_dialogue`：字幕转述线下快速加微信、同理心、幽默和快速咖啡邀约；对方说困、上班累；约八天后轻量重启；“你不也没跟我聊吗”、社恐、怕冷场；地域和语音消息；加班、排假、休息日、朋友同行、地点和当天见面。
- `source_interpretation`：讲解者把初始吸引较弱、回复、表情、问号和“下周看看”解释为窗口、测试或兴趣；把社恐和冷场解释为真实顾虑；把排假和具体休息日解释为更可靠的调度信息。心理归因与观察事实分开保存。
- `source_move`：来源先用同理心和低负担邀约，面对疲劳时放下当次安排，重启后承接社恐/冷场顾虑，再进入排假、时间、同行和地点调度。语音消息只记录发送形式，不等同电话许可。
- `source_feedback`：材料报告对方持续解释工作和身体状态，继续参与顾虑讨论，后来提前告知休息日并协商同行和地点；结果由来源报告为完成见面。
- `source_principle`：来源强调初始吸引不足时先建立可继续互动，明确顾虑出现时先承接，再决定是否回到邀约；固定八天、推拉和“窗口”解释不成为阶段硬条件。
- `source_outcome`：来源报告最终见面；无独立原始聊天导出、现场证据或后续关系质量，结果状态为 `source_reported`。

### 调用边界

`K-20260822-039` 可作为相似案例候选召回，帮助识别“低吸引—疲劳暂停—新证据重启—顾虑承接—具体调度”的路径。社恐、怕冷场、上班累和排假不能解释成必须突破的阻碍；语音消息不能替代电话接听确认。

## 八、待验证问题

1. “明确不适/删除后自愿恢复”是否需要独立于普通停止边界，还是只作为停止边界后的特殊案例分链？
2. 低吸引、疲劳和社恐顾虑在不同案例中是否稳定构成同一阶段节点，还是应拆成身体限制与社交顾虑两个节点？
3. 见面后明确说“需要征求意见”与删除之间，运行时应如何记录当前话题停止和整体互动停止的层级？
4. 具体排假、同行和地点信息能否在失败案例中同样出现，仍需反例验证，不能直接视为兴趣强度。
5. 语音消息到电话的切换条件仍缺少更多有明确接听许可的案例。

## 九、下一步建议

下一步继续收集不同结果的讲解型案例，优先补充：

- 明确拒绝或删除后没有恢复的案例；
- 详细排假和行程仍最终取消的案例；
- 初始吸引较弱但不涉及社恐顾虑的案例；
- 见面后明确表达舒适或不适、并有完整后续的案例；
- 文字切换电话前明确询问且得到许可的案例。

累计 10-20 条脱敏真实聊天或可核验案例后，再对阶段节点、分链转移、顾虑信号和案例召回做第一次开发者审核。本批不生成完整聊天回复，运行时继续按“证据 -> 阶段/分链 -> 方向 -> 用户明确选择后才给示例”的顺序工作。
