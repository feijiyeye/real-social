1. 后续经典案例主要是课程讲解、逐句复盘或代聊分析，没有独立原始聊天导出是常态，不再作为阻断抽取的缺陷。

5. “给女性赋格/赋格她的行为”归入“资格奖杯/认可”操作映射，不新增第三条赋格信号定义。
6. “不想跟你讲话”先停止当前话题，再结合后续主动互动判断整体状态；明确要求结束全部互动时整体停止。
7. 阶段结构采用“阶段节点 + 多分链”，不设唯一主链；本案例的适配链只是候选分链。
8. `K-20260822-025` 可作为相似案例候选召回，但案例来源内容不自动成为默认方向或正式规则。

## 三周目提炼出的底层逻辑

```text
线下初识后的线上激活
-> 明确男女意图和跨城主题
-> 根据信号调整吸引/联系与短期/长期属性
-> 低反馈时撤回或维持连接
-> 顾虑显性化后转向信任、安全和关系预期
-> 再次连接邀约
-> 交换时间条件并确定日期
```

案例最重要的贡献不是某几句话，而是一个反馈驱动的调整模型：讲解者先判断当前缺的是吸引力、联系感、短期属性、长期属性还是顾虑处理，再选择本轮动作；对方反馈后继续、降级、换线、暂停或回到邀约。

## 新增候选

### K-20260822-026：适配到签约阶段分链

把用户术语目录与案例路径对齐为一条候选分链：激活、主题、调整、断裂期、签约。该映射能开始支持阶段节点识别，但“断裂期”对应最弱；后续案例可以提供不同路径，不能把本链设为唯一主链。

### K-20260822-027：动态调整规则

来源反复使用“吸引力有但信任感不足”“短期给够后往长期拉”“普通聊天久了再回到主题”等判断。本单元把它们抽成条件、动作和反馈循环，填补原来 `rule = 0` 的空白。

### K-20260822-028：亲密话题反馈调节方向

保留讲解中的成功与失败片段：较低强度进入，对方接住时维持或小幅提高；没有接住时降级、换线或暂停。它不是原句话术库。

### K-20260822-029：停止当前话题与后续判断（已裁决）

女性A说“不想跟你讲话”后仍继续回应并提供可用时间。用户裁决为先停止当前话题，再结合后续主动互动判断整体状态；明确要求结束全部互动时整体停止。两种来源解释继续保留，但不再阻断运行时。

## 原先被“排除”的内容如何处理

前一版把“不适合默认推荐”误处理成了“从案例知识中排除”。本次已改正：

| 内容 | 新处理方式 |
| --- | --- |
| 点赞、表情、称呼变化被解释为兴趣或需求感 | 保留讲解者的完整推断链，标为 `source_interpretation` |
| 沉默、未回复、拍一拍和再次联系 | 保留操作、目的、反馈与讲解结论，单独判断调用状态 |
| 把回避或反驳解释成装、测试、口是心非 | 保留为来源心理读取方法，不删除 |
| 亲密/性话题和强度升级 | 保留成功、失败及回撤逻辑，并抽成候选方向 |
| 隐性铺垫跨城到访、奖品性和拉扯 | 保留完整目的链，标为来源逻辑；是否默认调用另审 |
| 物化式标题、激烈表达和结果宣称 | 三份原文完整保留，案例层说明其在来源叙事中的位置 |

既有 C 类裁决仍限制相关内容直接升级为默认可调用规则，但不再用于删掉经典案例中的素材和逻辑。
