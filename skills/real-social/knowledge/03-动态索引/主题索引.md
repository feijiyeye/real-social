# 主题索引

主题地图在达到关联条件后建立，用于快速进入当前有效知识。

主题不会提前创建。只有满足以下任一条件时，AI才建立主题地图：

- 至少有 3 个有效知识单元共同指向同一问题；
- 用户连续多次围绕同一主题提问；
- 用户明确要求建立某个主题入口。

建立主题时必须：

1. 优先复用已有主题名和别名。
2. 将同义主题合并为一个主名称。
3. 允许同一知识单元出现在多个主题中。
4. 主题地图只做导航，不复制知识正文。
